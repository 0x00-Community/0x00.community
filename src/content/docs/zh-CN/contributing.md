欢迎所有人参与贡献：代码、文档、基准测试、问题报告和想法都算。

## 报告问题

在对应项目的仓库里开 issue。好的报告应包含版本或提交号、平台、能复现问题的最小输入，以及你期望的结果。

## 提交改动

1. Fork 仓库，从 `main` 拉出一个分支。
2. 每个 pull request 只做一件事，并说明**为什么**需要它。
3. 确认项目测试在本地通过。
4. 向 `main` 发起 pull request。每个仓库的 `main` 分支都受保护：所有改动（包括维护者自己的）都通过 pull request 合入。

## 文档

每个仓库都提供英文（`README.md`）和简体中文（`README.zh-CN.md`）两份 README。改了其中一份，请同步另一份，或在 pull request 里注明，方便其他人帮忙翻译。

## 本网站

本站源码在 [0x00-Foundation/0x00.community](https://github.com/0x00-Foundation/0x00.community)。博客和文档是 `src/content/` 下的 Markdown 文件，每种语言一个目录。

Everyone is welcome to contribute — code, documentation, benchmarks, bug reports and ideas all count.

## Reporting issues

Open an issue in the repository of the project concerned. A good report includes the version or commit, the platform, the smallest input that reproduces the problem, and what you expected to happen.

## Sending changes

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change, and describe *why* it is needed.
3. Make sure the project's tests pass locally.
4. Open a pull request against `main`. The `main` branch of every repository is protected: all changes, including maintainers' own, land through pull requests.

## Documentation

Each repository ships its README in English (`README.md`) and Simplified Chinese (`README.zh-CN.md`). If you change one, please update the other or mention it in the pull request so someone can help translate.

## This website

This site lives at [0x00-Community/0x00.community](https://github.com/0x00-Community/0x00.community). Blog posts and docs are Markdown files under `src/content/`, one folder per language.
